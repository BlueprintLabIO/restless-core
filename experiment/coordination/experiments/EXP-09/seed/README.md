# Continuous Value Lab

This is an isolated `_test` publication used to evaluate continuous organisational behaviour. It is
not the public Restless site and none of its signals establish market or customer facts.

The accepted publication lives on `main`. A new cycle must begin from the current accepted commit and
must never reconstruct the publication from summaries or a prior worktree.

Run `python3 verify.py` to check the exact repository contract. Semantic quality remains the
responsibility of a fresh peer reviewer and the accountable publication lead.
