# EXP-01 W01 — session mitosis screen

**Status:** activated; mechanism probe pending

## Trigger and hypothesis

E02 recorded `C1` and `I3`: the ordinary Work brief named all 32 source IDs but did not carry the
frozen source cards from the lead's request context. The worker substituted unrelated repository
evidence, and the lead had to reject and rebuild the full contribution.

W01 tests whether a lead and producer forked from one exact completed kickoff history can preserve the
task's causal context while keeping separate artifact ownership. It must beat an ordinary B1 handoff on
orientation/communication and reintegration without worsening the native outcome or creating correlated
errors.

## Cheapest falsifier

Use the installed first-party `codex exec fork` primitive on one completed kickoff session. Prove:

1. two fresh child session IDs derive from the same recorded parent ID;
2. the common kickoff transcript and owner-task bytes have frozen hashes;
3. Sol lead and Terra producer receive different post-fork roles and operate on separate Git branches;
4. each child produces only its assigned sentinel artifact and clean commit; and
5. neither child writes the sibling branch or changes model/role authority.

Failure to preserve lineage, branch separation or role/model divergence blocks W01 before a product
comparison. The shared parent necessarily grants both children a common run-root sandbox; this is
accepted for the isolated experiment but is a production-authority risk, not a production design.

## Complexity charged

The screen charges the kickoff model turn, fork orchestration, two child transcripts, branch setup,
reunion turn, lineage hashing and authority audit. Transcript replay or ordinary prompt duplication
does not count as session mitosis.
