# EXP-03 final results — the supervised company

**Completed:** 24 August 2026
**Disposition:** accepted evidence; no universal team-size winner
**Model:** live first-party `zai/glm-5.3` for every producer, supervisor and semantic reviewer
**External effects:** none

## Main answer

The strongest current Restless organisation is **wide, shallow and supervised**:

```text
owner → available Exec → one non-producing accountable lead per outcome
                         → one end-to-end worker by default
                         → temporary extra workers only across value-producing boundaries
```

The lead/worker separation is an owner decision and remains even when it adds local cost. EXP-03's
empirical result is about what should sit below that lead. More workers help only when they add
differentiated expertise or independently closing capacity without creating a central rewrite
bottleneck.

## Validated harness repairs

The sprint did uncover real code faults, which were repaired before the final T5 disposition:

- telemetry now streams reply-free events over one persistent connection instead of opening one
  connection per token;
- coordinator clients can carry multiple messages safely and disconnect without callback storms;
- repository custody/cleanliness is proved by the harness, while artifact fidelity is proved by an
  archive-native verifier that receives no `.git` metadata;
- completion rejects any candidate unless the canonical checkout is the exact commit and clean;
- postflight recertification can establish preserved truth without mutating the terminal record.

Fresh evidence: four-primitives conformance 16/16; fault/restart suite 41/41, including 256 ordered
one-way notifications; supervisor conformance 16/16; multi-worker conformance 9/9; Rust release build,
format check and Python compilation passed. T5 S3 then passed exact postflight protocol and native

## Economics and bottlenecks

Across the nine counted supervisor cells, provider-reported model cost is **$16.17198152**: $5.56824936
of supervisor calls and $10.60373216 of worker calls. This is a lower bound: T1 C0 and T4 S1-T were
forcibly ended before complete usage returned. The $4.3736 pre-patch T2 diagnostic and semantic blind
review calls are separately excluded from matched-cell economics.

Handoff and recovery often share one supervisor call, so the trace cannot honestly allocate every
token between them. The isolated costs are still revealing: T4's $0.047117 material-event wake
prevented zero stale work; T3 Q2's assembler alone cost $0.54086524; and T5 S3's post-synthesis
reinspection/repair path cost at least $1.52374488 before final acceptance review. The dominant drag
was long model/tool cadence, late verification and serial synthesis—not status polling or missing
worker intelligence.

## Enduring versus contingent

Enduring:

- one accountable integrator per outcome;
- Exec owns portfolio dispatch, not department execution;
- the lead preserves mission and judges but does no planned production;
- split only where another actor returns independently useful value;
- repeated units scale only when they close locally;
- events carry changed information; elapsed time is a budget, never semantic truth;
- real artifacts and observable outcomes outrank agreement or self-report;
- Work remains a sparse responsibility/evidence graph.

Contingent on current models/runtime:

- default worker span of one;
- the exact T2 two-specialist crossover and T3/T5 losses;
- GLM-5.3's slow cadence at `high`;
- ACP/OMP/provider cache, reasoning-token and in-flight usage visibility;
- any fixed cost, minute or token threshold.

## One bounded implementation recommendation

Port the **truthful completion path** into the production ownership boundaries: Attempt-scoped
artifact identity, exact clean completion, judgement-to-revision recovery, archive-native review and
event-stream/postflight truth. Do not add a workflow engine, task router, shared transcript, semantic
blackboard or universal artifact lifecycle. The experiment harness already proves the smallest shape.

The next experiment should isolate two remaining questions rather than search more topologies:

1. effort/cadence control — matched effort tiers, observable phase/usage checkpoints and a protected
   closure reserve, without raw chain-of-thought sharing;
2. a genuine locally closing queue — workers complete attributable units that aggregate through a
   deterministic projection, with no model assembler.
