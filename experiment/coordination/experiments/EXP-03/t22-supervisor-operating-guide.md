# EXP-03 supervisor operating guide

**Authority:** empirical default beneath the owner-decided supervised-company architecture
**Scope:** current GLM-5.3-class actors and the Restless Work/Attempt/artifact substrate

## Fixed organisation

Exec always assigns an executable owner outcome to one accountable lead and returns to portfolio
availability. The lead remains a non-producing mission keeper even with one worker. The worker owns
production; the lead frames, commissions, observes, redirects, rejects or accepts, and prepares the
exact outcome for review.

## Smallest useful team

| Work shape | Current default | Expand only when |
| --- | --- | --- |
| One coherent artifact or tightly coupled change | lead + one end-to-end worker | a differentiated seam produces evidence or expertise the first worker cannot cheaply retain |
| Mixed strategy then execution | lead + one worker; optionally two sequential specialists | the upstream artifact materially changes downstream choices and blind whole-outcome quality repays the extra boundary |
| Independent evidence regions | lead + one analyst | corpus/context, access or expertise actually saturates one analyst; each region return is independently useful |
| Repeated accounts/cases | lead + locally closing unit workers | units need no shared model rewrite; viable backlog and marginal accepted throughput remain positive |
| Volatile or consequential operation | lead + smallest producer set | material events can truly interrupt/redirect work or partial actions can cause harm |

Current measured span is one for coherent work and one for any batch that requires a model assembler.
Two sequential specialists have one scoped marketing quality win. Three complementary research workers
lost. Q2's two producers plus assembler lost, so Q4/Q8 stopped. These are curve points, not universal
headcount laws.

## Communication and events

- Brief purpose, exact responsibility, observable success, exact inputs/tools, consequential
  constraints, authority boundary and return surface.
- Communicate a changed fact, decision, question or artifact only when it can alter another actor's
  work. Free-form causal explanation is welcome; activity narration is not required.
- Quiesce while useful work proceeds. Wake at artifact, terminal, block or judgement request.
- Use a material wake only when the runtime can affect the live Attempt, the partial effect can cause
  harm, or continuing would waste irreversible work. A next-wake message is not an interrupt.
- Inspect the native artifact and exact candidate, not worker confidence. Content correction returns
  to a worker; exact promotion is supervisory judgement, not production.

## Truthful completion substrate

Retain the four proved recovery semantics rather than adding a workflow engine:

1. immutable Attempt-scoped artifact references;
2. explicit completion against the exact clean candidate;
3. judgement resolution that reactivates the same Work at a new revision;
4. archive-native review, with repository custody proved separately by the harness.

Telemetry uses one persistent reply-free event stream. A preserved run may be explicitly recertified
postflight, but its original terminal summary is never rewritten.

## Effort and observability

EXP-03 held every actor at `high`, so it does not identify an optimal reasoning-effort policy. It does
show that long analysis/tool loops and late proof can consume the closure window. The next controlled
surface should align an **effort envelope**, not expose private chain of thought:

- configured effort tier, spend/time envelope and consequence level per responsibility;
- a protected closure reserve for proof, return and supervisory judgement;
- observable phase (`orient`, `produce`, `verify`, `handoff`, `repair`) plus tool/liveness and usage
  checkpoints;
- explicit rationale, uncertainty and requested decisions in handoffs;
- worker-requested effort escalation when evidence changes the task.

Do not use raw reasoning traces as the coordination API or durable company memory. They are noisy,
provider-dependent and may be unavailable. Coordinate through decisions, uncertainties, artifacts,
observable phase and actual outcomes. EXP-03's provider exposed total/output usage but not reliable
reasoning-token or cache attribution; those fields remain unknown rather than inferred.
