# EXP-02 A1 — authoritative commission-context screen

**Status:** rejected after P1 replication.

## Question

Does attaching one exact authoritative source locator and digest to an otherwise natural commission
prevent a Terra producer from losing the owner corpus, without turning the handoff into a template or
large eager context dump?

## Activation evidence

In EXP-01 E02, the ordinary producer Work named source IDs but omitted the frozen source cards. Terra
substituted unrelated repository evidence; Sol rejected the contribution and rebuilt the whole ledger.
That is observed `C1` + `I3` + `E5`, not a speculative inconvenience.

## Baseline and changed variable

| Arm | Staff Attempt input |
|---|---|
| R0 | Existing natural Work outcome, actor/role, Work/Attempt, workspace/branch, capability capsule, feedback, required artifacts and gates |
| A1 | R0 plus the absolute locator, SHA-256 and byte length of the immutable owner directive/frozen corpus already held by the run |

A1 does not paste the corpus into the prompt. Terra retrieves the exact file when the responsibility
requires it. The lead remains free to phrase the commission and retains cross-region synthesis,
integration and final judgement.

## Fixed envelope

- P3 task/evaluator: the immutable R-LH-01 scenario and external evaluator;
- seed: `514b7b3d0a65e093af608b08ca142344412181f4`;
- lead: `gpt-5.6-sol`, medium reasoning;
- available producer: `research-analyst` on `gpt-5.6-terra`;
- natural N1 leadership, one Staff slot, event-driven completion, no semantic actor timeout;
- identical tools, native target, model envelopes and hidden evaluator;
- no live-company or consequential effect.

## Conformance and negative control

`exp02-a1-conformance-r2` passed 10/10. Both prompts carried the same free-form Work outcome and
frozen scenario hash. R0 contained neither the A1 heading nor source locator; A1 contained exactly one
locator and exact digest. The first conformance run failed one probe assertion because its checker did
not normalise a Markdown line wrap; no model ran and the mechanism was unchanged.

The external negative control remains the untouched R-LH seed (34/36 expected failures). A1 is invalid
if Staff cites a source absent from the frozen corpus, takes over the lead-owned decision, or the
evaluator is exposed.

## Win and stop rule

A1 wins the screen only if Staff uses the frozen corpus, returns an independently useful artifact,
lead reimplementation materially falls, final quality is non-inferior and added retrieval/context cost
is smaller than the work it prevents. A clear first live loss stops and deletes the A1 harness branch.
A win is provisional until replicated on two coding shapes and one non-coding shape.

## First result

See [`a1-p3-result.md`](a1-p3-result.md). A1 removed the exact source-loss/reimplementation failure,
won blind founder review 9.3 versus 9.0 and was 5.6% faster, while both arms failed 27/36 and A1 used
16.2% more newly processed input. It advances to replication, not product promotion.

## Replication result

[`a1-p1-result.md`](a1-p1-result.md) records the coding replication. A1 tied the 18/18 external gate
and was 16.8% faster, but lost fresh blind native-artifact review 7.6 to 9.0 on material truth and
spatial semantics. The first-clear-loss rule stops and purges the mechanism.
