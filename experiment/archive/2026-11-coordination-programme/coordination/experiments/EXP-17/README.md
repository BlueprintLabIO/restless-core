# EXP-17 execution record

**Status:** Concluded — sparse first pairs complete; `C` wins observed efficiency cells at outcome parity

**Sprint:** [Codex solo versus Restless-supervised Codex](../../../exp-sprints/exp-sprint-17-worker-architecture-benchmark.md)

## Result

Eight valid counted runs closed four work-shape cells after one symmetric LC-2 replay repaired an
invalid hidden evaluator. Every valid candidate passed its native gates. Two fresh source-blind GPT-5.6
reviewers accepted every candidate, with paired mean-score differences between `0.05` and `0.53`
points. `R1` added 77% to 194% latency and 74% to 230% spend in each cell without a measured quality,
recovery or continuity advantage. `C` is therefore the observed performance default for all four
sampled shapes. This does not remove supervisor accountability from live-company governance.

`RP-Q2` remains the next priority experiment. It was not run because the activation freeze contains no
exact parallel controller, unit split, label, order or budget commitment; adding those after seeing the
first-pair results would be post-outcome protocol design.
