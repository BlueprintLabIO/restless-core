# Experiment sprints

Experiment sprints are founder-approved execution contracts for empirical work. They use the same
discipline as product sprints—outcome, acceptance criteria, risks and review—but their deliverable is
decision-changing evidence rather than a production feature.

An experiment-sprint approval authorises only the named isolated runs and supporting harness work. It
does not authorise live-company effects, production promotion or an expanded task portfolio.
