# Dream office floor studies

Six standalone, animated spatial concepts for the company office:

- Tree Commons
- Hearth Lounge
- Greenhouse Café
- Garden Court
- Library Forum
- Seasonal Studio

The gallery deliberately keeps the simulation lightweight: authored safe walking loops, the existing
Pixel Agents character/furniture sprites, and canvas-drawn concept scenery. It is a scratch comparison,
not product architecture.

Each study includes a different care layer rather than a generic furniture scatter: stocked food and
hydration points, quiet focus booths, stretching or recovery corners, pet beds and bowls, cycle storage,
reading nooks, coat storage, tea service, or maker supplies according to the character of the floor.

From the repository root:

```sh
python3 -m http.server 4188
```

Then open <http://127.0.0.1:4188/experiment/dream-office-demos/>.
