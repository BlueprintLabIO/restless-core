# Restless systemd user services

The Linux contract is generated by `restlessd::appliance` and covered by the
same secret-free tests as the counted macOS service. The released shapes are:

- `restless-plane.service`, a restartable user service;
- `restless-wake-due.service`, a wake-only one-shot; and
- `restless-wake-due.timer`, a persistent timer that carries no company work.

Live Linux installation remains deliberately unclaimed until its user journey
is counted. Restless, not systemd, remains the durable schedule authority.
