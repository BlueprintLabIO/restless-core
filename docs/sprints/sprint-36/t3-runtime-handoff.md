# S36-T3 — Hand off without exposing the Runtime

**Layer:** Runtime Bridge and capability boundary

**Observed outcome or friction:** A convenient reverse proxy or port forward can accidentally make the
company computer—not the intended artifact—the hosted product.

**Work:** Submit the immutable candidate through the existing outbound Bridge under an exact grant.
Prove there is no supported inbound route to the Runtime, owner API, OrgIntel or Bridge; no provider,
DNS, registry-root or supervisor credential enters the cell; and no source/browser/model volume appears
in the service handoff.

**Evidence:** Network and mount probes permit only the declared candidate payload and outbound control
exchange. Hostile candidate metadata cannot broaden the grant or select another company resource.

**Deletion target:** Runtime-wide hostname assignment, raw tunnels, Docker socket access and provider
CLI credentials inside the company.
