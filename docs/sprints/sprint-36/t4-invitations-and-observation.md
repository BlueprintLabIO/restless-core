# S36-T4 — Issue scoped invitations and observe the result

**Layer:** Account plane, Authority and OrgIntel

**Observed outcome or friction:** A shared URL is neither an access model nor evidence that the right
build and audience used the service.

**Work:** Issue signed, expiring publication invitations suitable for HTTP/WebSocket or Godot join
documents. Bind them to exact publication, audience, endpoint and build. Record bounded readiness,
connections, crashes and usage from the provider without ingesting application payloads or player
activity surveillance.

**Evidence:** Valid invitations work only within scope. Expired, revoked, cross-company, superseded and
tampered tokens fail. Unknown provider measurements remain explicitly unknown.

**Deletion target:** Permanent bearer URLs, owner-session reuse and a universal traffic or telemetry
ledger.
