# S11-T0 · Freeze the trustworthy delegated-turn contract

**Layer:** Cross-layer contract spanning OrgIntel, Authority, Runtime and owner projection.

**Observed friction:** The Aris run carried intent, agent context, Work, tools, gates, effect authority
and live conversation through separate mechanisms. Each mechanism was locally plausible, but no
contract stated which source could decide delegation, capability, completion, publication or owner
history.

## Outcome

Write one implementable sequence from owner intent to observed external outcome. Assign every fact to
one authoritative layer and classify it as deterministic or judgement. ACP is the agent transport;
it does not become another source of company truth.

## Acceptance

- The contract names the source of actor/model preference, actual attempted model, Work/Attempt,
  gates, Runtime capability, effect authority/receipt, durable messages and ephemeral live events.
- A failure table covers malformed agent termination, failed gate, Runtime loss and effect ambiguity.
- Waiting, blocked, continue and outcome-met have non-overlapping operational meanings.
- Hidden reasoning, prompts and secrets are explicitly excluded from the owner projection.
- No universal command/capability type, workflow engine, second ledger or custom ACP replacement is
  introduced.

## Deletion

Makes prompt folklore and duplicated layer-specific interpretations of “done”, “waiting” and
“capability available” deletable.
