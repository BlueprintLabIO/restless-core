# S07-T5 · Dogfood three attention shapes, measure comprehension, purge the losing representation

**Layer:** All touched layers.  
**Serves:** the complete Sprint 07 success contract.  
**Depends on:** S07-T1–T4.  
**Observed friction:** one Aris screenshot can invite a copy tweak that overfits a disk incident while
leaving the presentation boundary unchanged.  
**Makes deletable:** the losing representation and any compatibility path that reintroduces raw
internal prose as owner meaning.

## Outcome

A scripted `_test` run proves outcome review, bounded decision/Authority approval, human last mile
and one locally resolved non-item. A genuine Aris item then proves that the accountable actor can use
the path and that the owner can understand it without decoding implementation history.

## Scope and evidence

- Preserve the supplied baseline capture and record its repeated claims and visible identifiers.
- Run source/provenance/freshness/action checks through OrgIntel and the attention API.
- Restart the stack and show the authored brief is unchanged.
- Run build/type checks plus a focused real browser review when the browser surface is available.
- Have an independent critic compare the brief to evidence; record unsupported claims or omissions.
- Run the next genuine Aris item, record the owner's ten-second account and source-owned action.
- Delete generic projection copy, Work-title reuse, raw-primary rendering, duplicated rail copy and
  any unused candidate payload.

## Pass condition

The sprint closes only when every Sprint 07 criterion has an observed evidence line in the run
report. A clean screenshot alone is not completion.
