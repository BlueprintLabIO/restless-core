# S33-T0 — Freeze product, channel, reference and anti-example corpus

**Serves:** [Sprint 33](../sprint-33.md) · Product contract / Evaluation

## Outcome

Freeze current product UI, approved public work, visual tokens, motion primitives, licensed external
references and rejected outcomes—including goofy graphics, uncanny pseudo-UI and text-heavy pages.

## Acceptance

- Every reference names source, licence, capture time, intended lesson and non-transferable qualities.
- Product captures bind to an exact product version and state.
- Positive and negative examples explain composition, density, typography, imagery, motion and proof.
- A restrained control exists for every effect-rich exercise.
- Evaluators see rendered artifacts without candidate rationale or component counts.
- Novelty, number of effects and similarity to one reference are never pass/fail.

## Makes deletable

Unattributed inspiration dumps and visual review based on isolated screenshots or library prestige.
