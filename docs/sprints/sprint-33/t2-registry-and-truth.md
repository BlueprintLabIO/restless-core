# S33-T2 — Join reusable primitives to product truth without quotas

**Serves:** [Sprint 33](../sprint-33.md) · Runtime resources / Registry

## Outcome

Make the existing interaction and component registry retrievable as capabilities under Visual Language,
while keeping product truth and outcome need—not registry availability—as the selection authority.

## Acceptance

- Retrieval uses purpose, environment, accessibility and channel compatibility.
- A primitive's framework, dependencies, performance, motion state and licence are inspectable.
- Exact product UI is used when evidence is required; otherwise abstraction is visibly abstract.
- No standard, channel or visual release maps to a component/effect quota.
- Unsupported or stale primitives fail before production rather than becoming placeholders.
- Reuse records the primitive version actually used without copying the whole registry into context.

## Makes deletable

Manual component archaeology, effect-count quality heuristics and uncanny hand-drawn pseudo-product UI.
