# S42-T0 — Freeze the mixed application corpus

**Layer:** Runtime/product evaluation  
**Serves:** Application roles should be extracted from observed software rather than a speculative ontology.

## Work

- Freeze four shapes: Codex as harness plus interactive client, an ordinary CLI tool, an existing GUI
  or project application and one company-built tool/service.
- Record exact build/source, entrypoints, platform, state ownership, readiness, current launch path,
  authentication and roles actually exercised.
- Include install, update, failed update, rollback, disable, role removal, uninstall with retained data,
  full removal and Runtime replacement.
- Record baseline duplicated fields and owner friction in current harness/resource/desktop surfaces.

## Acceptance

Every proposed shared field is used by at least two counted shapes or remains application-specific.
The corpus names expected filesystem/process state and refuses to enumerate every executable on PATH.

## Makes deletable

Speculative registry fields and application categories unsupported by real work.
