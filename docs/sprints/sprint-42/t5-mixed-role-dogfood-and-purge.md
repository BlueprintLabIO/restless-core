# S42-T5 — Dogfood mixed roles and purge special cases

**Layer:** Full product  
**Serves:** The shared application model earns permanence only if it simplifies real lifecycle and use.

## Work

- Exercise the four-shape corpus through install/readiness/use/update/rollback/disable/role removal and
  exact uninstall or retention.
- Run autonomous harness, native takeover, ordinary tool, GUI/project application and company-built
  tool cases without changing their expected semantics.
- Inject hostile package metadata, path traversal, wrong digest, stale role, failed probe, config
  contamination, Runtime replacement and cleanup ambiguity.
- Compare owner actions and implementation duplication before/after the model.
- Delete superseded per-harness/app lifecycle fields and all unused generalized machinery.

## Acceptance

Every shape remains usable and truthful, role changes never widen authority, state survives or deletes
as declared and the shared model removes measurable duplication. Otherwise close the sprint negative
and retain static profiles.

## Makes deletable

The frozen migration adapters, duplicate lifecycle paths and any unused application ontology.
