# S42-T4 — Place applications in Resources and Company Computer

**Layer:** Owner cockpit  
**Serves:** Owners need application readiness and use without a new storefront or infrastructure dashboard.

## Work

- Extend Company Resources with compact identity, installed/observed build, readiness, admitted roles,
  trust class, auth requirement, state ownership and bounded lifecycle actions.
- Extend Company Computer/Open behavior to launch or attach applications that expose a usable
  interactive role.
- Keep harness defaults as company execution policy and Take control as contextual Work behavior.
- Explain unavailable, incompatible, update-required, externally authenticated and personal states in
  owner language.
- Preserve narrow layouts, keyboard operation and current quiet-status patterns.

## Acceptance

An owner can find what is installed, understand what each application may do, open it where useful and
predict update/removal effects without seeing a package registry, raw command or duplicated harness page.

## Makes deletable

Scattered version badges, provider setup commands and decorative application cards.
