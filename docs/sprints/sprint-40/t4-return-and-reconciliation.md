# S40-T4 — Return control with bounded reconciliation

**Layer:** Runtime Bridge + OrgIntel + owner cockpit  
**Serves:** A one-way native link abandons company continuity at the exact moment it matters.

## Work

- Observe post-control Git status, commits, diff, created/deleted files, owned process/service changes,
  native thread identity and provider usage where available.
- Join governed effects only through existing Authority receipts; mark opaque GUI/network effects and
  unobserved commands unknown rather than inferring them from prose.
- Produce one bounded change account relative to the pre-control checkpoint, including a no-change
  result and conflicts or dirty state requiring owner action.
- Let the owner resume, redirect, reassign, restore the checkpoint or remain paused through existing
  Work semantics.
- Ensure reconstructed activity cannot duplicate messages, tool effects, usage or decisions.

## Acceptance

Every corpus case returns one idempotent account and control disposition. The account survives restart,
never upgrades unknown evidence, and cannot complete Work or resolve Attention without the existing
typed action.
