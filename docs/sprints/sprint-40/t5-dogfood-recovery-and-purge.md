# S40-T5 — Dogfood Codex takeover, recovery and cleanup

**Layer:** Full product  
**Serves:** The control path must improve a real intervention and survive failure, not only pass API tests.

## Work

- Run the frozen hard-goal and productive-edit journeys from managed Codex through native control and
  back to an accepted company outcome.
- Inject active-turn race, client crash, App Server death, Runtime restart, abandoned control,
  reassignment, cross-scope handle and no-change return.
- Inspect worktree, process tree, session storage, sockets, handles, environment, logs, canonical
  messages, usage and Authority receipts before and after each case.
- Record owner actions/time, attachment latency, intervention value and reconciliation omissions.
- Remove prototype ports, shell instructions, duplicate pause state and test-only bypasses.

## Acceptance

A fresh reviewer reproduces the counted journey from the release image. It retains one exact thread,
one workspace, one controller and one canonical company account, with no secret or process residue and
materially less recovery friction than starting an unrelated native session.

## Makes deletable

The manual takeover checklist and every losing attachment/reconciliation implementation.
