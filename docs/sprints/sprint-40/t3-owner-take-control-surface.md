# S40-T3 — Add the owner Take the controls surface

**Layer:** Owner cockpit + local launch client  
**Serves:** Native access is useful only when the owner can find it from the Work that needs help.

## Work

- Add **Take the controls** to eligible existing Attention, Work and active-session contexts without a
  new developer or harness page.
- Show the target actor, Work, harness, exact attachment relationship, current activity and what will
  pause before confirmation.
- Reuse Company Computer/Open launch behavior for the native terminal and show preparing,
  owner-controlled, uncertain, returning, unavailable and expired states.
- Offer **Return to Restless** and keep existing typed resolution actions visually and semantically
  separate.
- Preserve keyboard, small-window and failure-state behavior in the current product language.

## Acceptance

A source-blind owner reaches the correct native session, understands who currently controls it and can
leave it paused or return it without mistaking terminal exit for Work completion or Attention
resolution.

## Makes deletable

Provider-specific command instructions and hidden terminal-entry affordances.
