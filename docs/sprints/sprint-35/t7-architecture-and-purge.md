# S35-T7 — Promote proven architecture and delete losing machinery

**Serves:** [Sprint 35](../sprint-35.md) · Architecture / Closing audit

## Outcome

After both dogfoods pass, update target architecture with only the observed Company Identity contracts
and remove compatibility, prompt and registry paths made redundant by the programme.

## Acceptance

- Architecture names one source boundary, release/proposal semantics, bounded compiler and artifact binding.
- Truth, Voice, Visual and Culture remain distinct evidence types under one identity release.
- Existing Work, Attempt, Authority, effect and artifact lifecycles remain authoritative.
- Closing search finds no generic preference engine, quality/identity score, project identity, CMS,
  employee score, sentiment surveillance or self-training prompt loop.
- Duplicate prompt guidance, browser-local defaults and losing migration adapters are deleted with tests.
- Run evidence and independent judgements remain; raw model homes, credentials and transient captures do not.
- Sprint and programme status are updated from one canonical checklist after founder review.

## Makes deletable

The experiment-only identity compiler, compatibility sources and every abstraction that did not improve
the held-back transfer outcome.
