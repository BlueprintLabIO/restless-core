# S35-T2 — Bind artifacts to release, author, channel, truth and evidence

**Serves:** [Sprint 35](../sprint-35.md) · OrgIntel / Native artifacts

## Outcome

Record the exact identity release, applicable pillar evidence, channel contract, named/accountable author,
truth dependencies and native review identity for every accepted artifact.

## Acceptance

- Binding is immutable for an accepted artifact version and changes only with a new version.
- Mutable locators cannot make old identity evidence appear current.
- Truth dependencies are explicit enough to compute a bounded stale inventory.
- Authorship distinguishes producer, accountable lead, named signatory and company voice.
- Native captures and verdicts bind to exact artifact identity.
- Legacy artifacts remain readable with identity status unknown rather than fabricated.
- Binding adds no second artifact lifecycle or publication authority.

## Makes deletable

Filename-based brand inference and claims that an asset is current because its path has not changed.
