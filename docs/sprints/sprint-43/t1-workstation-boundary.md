# S43-T1 — Freeze the optional workstation boundary

**Layer:** Host + Runtime + Authority  
**Serves:** A rich GUI must not become a second unbounded company environment.

## Work

- Define exact machine/placement, application build, workspace mounts, display/input path, state roots,
  network routes, authentication owner, update owner and lifecycle.
- Bind launch to one company and takeover controller without granting host filesystem or credential access.
- Separate vendor application history/config from canonical Work, messages and Authority receipts.
- Define checkpoint, disconnect, crash, Runtime replacement, app update and uninstall behavior.
- Bound CPU, memory, disk, idle processes and startup/return latency for the activated cases.

## Acceptance

The workstation can be destroyed or disconnected without losing canonical company state or affecting
another company, and it cannot expand its own mounts, credentials, network or autonomous roles.

## Makes deletable

Ad hoc VNC/SSH setup, broad host mounts and undefined GUI state ownership.
