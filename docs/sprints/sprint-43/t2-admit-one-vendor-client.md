# S43-T2 — Admit one exact graphical vendor client

**Layer:** Runtime/host application integration  
**Serves:** The activation cases need the genuine vendor UI, not a Restless approximation.

## Work

- Install or connect the single T0-approved Codex or Claude graphical client through the Sprint 42
  application lifecycle and trust classification.
- Verify exact version, platform, source/signature, required services and application readiness.
- Open the correct company workspace and strongest proved session relationship through an opaque
  launch handle.
- Preserve vendor-native terminal, diff, preview or other counted capability without pixel automation
  becoming a harness API.
- Refuse wrong company/workspace/account/version and unsupported session-transfer claims.

## Acceptance

The real client resolves each activation case and identifies its exact workspace, account boundary and
session relationship. It is optional, owner-operated and removable without affecting managed work.

## Makes deletable

Prototype installers, manual remote commands and partial imitation UI.
