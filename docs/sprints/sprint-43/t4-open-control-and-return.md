# S43-T4 — Reuse Open, Take control and Return for the workstation

**Layer:** Owner cockpit + local client  
**Serves:** A vendor desktop should feel like entering the same company work, not launching a second product universe.

## Work

- Launch the admitted client from existing Work/Attention/Company Computer contexts with one bounded Open action.
- Show placement, company, workspace, account/trust boundary, current controller and session relationship.
- Reuse controller/checkpoint semantics and keep autonomous work paused while the graphical client owns control.
- Return through the common observed change account, marking opaque UI commands/effects unknown unless
  backed by Runtime or provider evidence.
- Handle window close, app crash, host disconnect, multiple windows and stale launch handle honestly.

## Acceptance

The owner can enter and leave the vendor UI without copied setup, duplicate Work or implicit completion.
The UI never presents personal application history, successful window launch or client exit as company evidence.

## Makes deletable

Desktop-specific Work state, copied workspace paths and bespoke return dialogs.
