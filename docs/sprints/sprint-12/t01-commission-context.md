# S12-T1 — Bind authoritative commission facts

**Layer:** OrgIntel + Company Runtime.

**Observed friction served:** a lead can naturally delegate, but retyping repository, role, current
revision, upstream artifact, feedback and capability facts creates omission and reconstruction churn.

## Outcome

The existing free-form commission creates sparse Work. At scheduler claim, the Staff Attempt receives
the exact authoritative facts Restless already owns and retrieves optional depth on demand. No form or
handoff language is required.

## Acceptance

- Work is created only for a real cross-actor responsibility or recovery boundary.
- Attempt claim atomically records the actor, revision, input fingerprint, upstream artifact versions
  and Work-linked feedback before launch.
- Runtime adds exact workspace coordinates, role, available skill roots and truthful capability probe
  locations to context.
- The lead's free-form purpose, causal understanding, unknowns and observable proof remain ordinary
  language rather than parsed required fields.
- A negative control with one omitted manual repository fact still launches correctly from bound
  authoritative state.
- Context accounting distinguishes automatically attached facts, retrieved depth and unused replay.

## Non-goals

- a universal commission schema;
- model-scored brief compliance;
- copying the lead's conversation wholesale unless EXP-02 A2 separately wins.

## Deletion target

Ad hoc kickoff assembly and any rigid template whose only purpose is to restate authoritative facts.
