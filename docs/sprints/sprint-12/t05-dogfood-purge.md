# S12-T5 — Dogfood, measure and purge

**Layer:** Full vertical slice.

**Observed friction served:** prompt wording and component tests repeatedly looked complete while live
company outcomes exposed missing delegation, missing callbacks, wrong wake altitude and unusable
review targets.

## Outcome

Scenarios A–E pass in isolated `_test` companies, then one bounded Cosmon repository outcome runs with
real models and tools. The owner receives its native target; the report preserves cost, timing,
interventions, counterevidence and deletions.

## Acceptance

- Freeze inputs, expected evidence and negative controls before each run.
- Observe two concurrent departments with Exec available, one valid solo decision and one real Staff
  contribution.
- Inject a material interface change and a missing semantic completion without timers or manual
  reconstruction.
- Restart daemon and Runtime separately and prove no duplicate Attempt or effect.
- Run the bounded Cosmon outcome with a real Runtime/model path and native playable or rendered target.
- Record outcome quality, time, actor usage, message information gain, recovery overhead and owner
  intervention without collapsing them into one score.
- Update the sprint checklist only from this evidence, update systematic learnings where warranted and
  delete losing adapters/fields/tests.

## Non-goals

- publishing Cosmon externally;
- using a simulated capability in a real company;
- retaining experimental affordances that did not win EXP-02.

## Deletion target

Every compatibility path, unused field, duplicate projection or experimental mechanism that no longer
improves the proved owner outcome.
