**Layer:** Owner-surface design research.

**Serves:** Sprint 10b criteria 1, 3, 13 and 18.

**Depends on:** —

but none has been compared inside the real Attention composition against equivalent company shapes.

## Outcome

Record one spatial grammar and one visual signature for production. The result may combine a small
number of proven ideas, but it must explain how 1, 2, 4 and 8 Teams adapt without turning each scratch
concept into a shipped mode.

## Work

- Place Tree Commons, Hearth Lounge, Greenhouse Café, Garden Court, Library Forum and Seasonal Studio
  inside the actual clear Attention layout.
- Use identical 1/2/4/8-Team, truth-state and viewport inputs for each candidate.
- Compare circulation, openness, perceived care, cue room, scale, occlusion, responsive behaviour,
  implementation cost and relationship to the cockpit palette.
- Name which architectural idea wins and which amenity ideas remain useful regardless of centrepiece.
- Record the decision before T1/T2 turn it into production machinery.

- Founder review covers 390, 768 and 1440 CSS pixels rather than one cropped floor image.
- Every candidate sees the same source fixtures and minimal surrounding UI.
- The decision names at least one rejected candidate and the observed reason it lost.
- No score function substitutes for founder judgement; rendered evidence remains attached.

through alignment; afterward retain only the compact evidence needed to understand the decision or
