# S31-T3 — Compile relevant identity into bounded Staff context

**Serves:** [Sprint 31](../sprint-31.md) · Runtime / Staff context

## Outcome

Compile a deterministic Identity Brief from effective release, outcome, channel, audience and author.
The brief references exact evidence and includes only the relevant truth and pillar observations.

## Acceptance

- Same inputs produce the same ordered brief and digest.
- A hard byte bound and explicit omission account prevent silent truncation.
- Conflicting or unavailable truth is surfaced, never summarised into certainty.
- At most a small relevant set of positive and negative examples is inlined; other evidence is linked.
- Irrelevant channel and actor history is absent.
- Context accounting distinguishes identity bytes from task and recovery context.
- No mode maps to a fixed author, critic, model, topology or example count.

## Makes deletable

Whole-brand-book prompt injection and ad hoc repository scans for “the current voice”.
