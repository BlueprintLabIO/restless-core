# S31-T1 — Add one canonical release and proposal contract

**Serves:** [Sprint 31](../sprint-31.md) · OrgIntel

## Outcome

Represent typed identity observations, pending proposals, immutable releases, lineage and the exact
release bound to a commissioned outcome using the smallest existing OrgIntel-compatible shape.

## Acceptance

- Released and proposed identity are impossible to confuse in serialized state.
- Release identity, predecessor, effective time, promoter and evidence locators round-trip exactly.
- Truth, voice, visual and culture retain distinct typed meaning.
- Historical outcome bindings survive release changes, restart and handoff.
- Invalid pillar, dangling evidence, lineage cycle and duplicate effective release fail closed.
- Schema and generated bindings have migration, legacy and restart fixtures.

## Makes deletable

Prompt-only brand state, asset-local “current style” flags and browser-local identity selection.
