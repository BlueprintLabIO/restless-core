# S31-T5 — Prove restart continuity, stale truth and no policy sprawl

**Serves:** [Sprint 31](../sprint-31.md) · Integrated evaluation

## Outcome

Operate one `_test` company through first release, two identity-bound outcomes, restart, conflict,
truth correction and a scoped exception. Record exact source and context evidence.

## Acceptance

- Both outcomes retain the same release across restart and handoff.
- The conflict blocks only the dependent claim and requires one decision-ready owner judgement.
- The correction creates a new release and identifies affected bindings without rewriting them.
- The exception applies only to its declared scope and expires correctly.
- Brief size and context failures are recorded; no whole-company replay occurs.
- Closing search finds no generic policy engine, project identity, prompt-only mode map or second Work
  lifecycle.
- Losing compatibility and duplicate identity paths are deleted with tests.

## Closing artifact

One bounded run report containing corpus digests, release lineage, brief digests, owner interactions,
stale bindings and purge evidence.
