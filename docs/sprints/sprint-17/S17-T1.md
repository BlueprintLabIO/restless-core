processes, while every wake receives fresh short-lived capabilities and proves its own tool contract.

without replay side effects; fall back explicitly to reconstructed context when absent; reject
cross-scope loads; observe required native/MCP tools before the first production prompt; compute
per-turn deltas from cumulative usage without inventing missing fields.
