into OrgIntel even across the commit/projection crash window.

relied on, and using email id as event identity collapses distinct lifecycle events.

correlation metadata; persist projection state/retry without cross-database transaction; reconcile
unprojected records after restart; make projection idempotent by stable Authority source reference.

**Deletion:** Detached best-effort projection and email-id event fallback.

**Evidence:** Duplicate, distinct-same-email, out-of-order and forced crash-window database scenario.
