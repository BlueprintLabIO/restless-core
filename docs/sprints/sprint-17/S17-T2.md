# S17-T2 — Repair terminal and telemetry truth

**Outcome:** Every process exit has an honest semantic terminal state and useful bounded telemetry;
the experiment harness can no longer manufacture event-driven or reasoning evidence.

**Layer:** Runtime terminal observation plus evaluation harness.

**Observed friction served:** A direct probe left an exited Attempt running, empty thought chunks
flooded traces, local completion coalesced globally and a 50 ms file poll impersonated a callback.

**Acceptance:** No-callback exit becomes unknown and wakes recovery; observable workspace state is
preserved; reasoning telemetry is bounded and contains no chain of thought; coalescing is scoped to
one causal outcome; external-event tests inject an explicit callback; process wait is event-driven.

**Deletion:** Probe terminal shortcut, empty per-chunk events, global closure query and file poller.

**Evidence:** Focused harness regressions and an observed no-callback recovery capsule.
