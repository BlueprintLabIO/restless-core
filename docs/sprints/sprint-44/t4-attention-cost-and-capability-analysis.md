# Sprint 44 T4 — Analyse attention, cost, and capability coverage

**Layer:** Product analysis

**Serves:** A positioning decision based on owner outcomes rather than aggregate benchmark scores.

## Work

- Analyse accepted outcome quality, owner active minutes, number and type of interventions, handoff tax, elapsed time, provider cost, and recovery effort.
- Report distributions and per-outcome results so one strong aggregate cannot hide a critical failure class.
- Identify native capabilities that remain unavailable, degraded, or expensive through Restless.
- Identify Restless capabilities that materially improve governance, continuity, parallelism, attention allocation, or recovery.
- Build a claim matrix showing which statements are supported, unsupported, or conditional for Codex, Claude Code, and the broader application model.

## Acceptance

- [ ] The analysis distinguishes outcome quality from owner-attention reduction.
- [ ] Takeover setup, context reconstruction, and return costs are visible as handoff tax.
- [ ] Capability gaps have an owner impact and recommended disposition.
- [ ] Results are broken down by outcome class and harness.
- [ ] Every proposed positioning statement points to a stated threshold and evidence.

## Makes deletable

- A single blended score that launders product tradeoffs.
- “Strictly better” language without a defined user, task class, and operating condition.
