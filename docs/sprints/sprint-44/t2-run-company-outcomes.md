# Sprint 44 T2 — Run the company-outcome corpus

**Layer:** Product proof

**Serves:** Direct evidence about which operating mode produces usable company results.

## Work

- Run every frozen outcome through each applicable comparison arm.
- Allow each native arm to use the certified capabilities that a normal expert user would reasonably use; record those capabilities rather than artificially constraining them.
- Capture final artifacts, review receipts, owner active time, interventions, elapsed time, provider cost, failures, retries, and takeover transitions.
- Preserve failed and partial outcomes in the dataset.
- Record whether a native-only capability, Restless governance feature, or transfer limitation materially changed the result.

## Acceptance

- [ ] Every corpus outcome has a complete or explicitly invalid result for every applicable arm.
- [ ] Evidence packets are sufficient for blind outcome review and later audit.
- [ ] Owner interventions and takeover boundaries are timestamped and classified.
- [ ] Failures and retries remain visible rather than being replaced by best-of demonstrations.
- [ ] Native features used by direct and hybrid arms are enumerated.

## Makes deletable

- Hand-curated demos standing in for repeatable product evidence.
- Claims that Restless wins only because the native client was artificially weakened.
