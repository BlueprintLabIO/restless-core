# Product media

- `restless-product-tour.mp4`: 30-second silent walkthrough using actual local browser captures, edited with chapter titles, fades and opening/closing cards. Browser capture cadence varies; the final video is rendered at 30 fps with frame blending. Waiting time in the desktop reconnection is cut for pacing. This is not an uncut task-completion benchmark.
- `restless-product-poster.png`: Full HD click-through poster for GitHub, where the README links to the MP4 rather than relying on an animated GIF.
- `../screenshots/*.png`: Full HD captures; provider account emails are explicitly masked. PNG publication avoids another lossy export, although the browser supplies JPEG source captures.

Captured 21 September 2026 from the development build. No simulated UI, generated product screens, or staged successful agent outcomes are included.
