## Harness behavior proved

- Typed Voice evidence commits atomically with its Identity evidence; an insertion failure cannot leave
  an untyped orphan.
- Named-author evidence is retrieved only for the matching author.
- A Work contract is set once, keeps its released Identity binding across continuation and distinguishes
  the author from the accountable actor who bound it.
- Staff receives the deterministic contract automatically; human-situation fields explicitly authorize
  no new fact.
- Native evidence is rejected unless it names the exact available artifact, renderer and the checks
  required by that channel.
- A consequential artifact producer cannot approve their own copy, and a superseded artifact cannot
  acquire a fresh current review.
- Typo and factual corrections create no Voice rule. A meaningful owner edit creates a pending,
  scoped proposal with exact before/after artifacts; it never changes the effective release.
- The CLI exposes evidence, binding, contract inspection, native render, review and owner-learning paths;
  these are not database-only methods.

## Defects found and repaired by the live run

1. **Author and binder were conflated.** The first CLI shape attributed the communication author to the
   actor binding the Work. The contract now records both separately.
2. **Flattened wire collision.** `voice-bind` reused `work_id`, already owned by the connected-tool input
   domain. The decoder accepted the field but routed it away from Company Voice. The command now uses
   the narrow `voice_work_id` wire name and has dispatch-domain coverage.
3. **False clean-room destruction.** `down --destroy` removed only the schema inside a per-company cell
   database, leaving the database, role and credential behind. It now closes every clone of the cell
   pool and removes the exact database, role, legacy test schema and credential directory.
4. **Stale reads could recreate destroyed state.** The lazy registry would provision an OrgIntel cell
   for a company whose config no longer existed. It now fails before any database or credential effect,
   with a regression test proving a stale name cannot recreate a cell.

The final `_test` company was destroyed. Its container/volume were absent; its cell, spend history,
Authority test records and config were removed. The static gallery remains as the reviewable closing
artifact.
