# Sprint 33 visual evaluation grammar

Review the native artifact before reading how it was made. Do not reveal component names, effect count,
producer rationale or reference similarity. Compare each effect candidate with a restrained control under
the same facts, hierarchy and viewport.

Accept only when the artifact:

- is recognisably the same company for product-grounded typography, composition, state colour or motion;
- uses exact current product evidence or an unmistakably abstract mechanism;
- makes the outcome and proof legible before decorative detail;
- uses motion to explain state, causality or emphasis and has a complete reduced-motion composition;
- survives the channel's real narrow/static/focus constraints; and
- has no mechanical accessibility failure.

Record concrete findings for identity, hierarchy, density, proof, product fidelity, motion and visible
defects. A visual departure is rejected, scoped as an exception or proposed as evidence. It never drifts
silently into the company release.
