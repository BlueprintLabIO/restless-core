## Defects found and repaired

1. **False immutable binding.** The initial idempotent insert compared only constitution digest after a
   conflict. Changed channel, author or native evidence silently returned the old row. Binding now
   compares every field and the exact evidence set inside one transaction before any dependency can be
   added.
2. **Duplicated runtime identity.** Staff separately appended Identity, Voice, Visual and Culture
   sections. This made outcome teams responsible for integration and spent context four times. One
   constitution compiler and one accounting record now replace all four paths.
3. **Rewritten applied migration.** `bound_by` had been added to migration 0027 after the `aris` cell
   applied it, preventing daemon boot. Migration 0027 is restored byte-for-byte to its shipped SHA-384;
   migration 0030 adds the proved field forward and removes the temporary default.
4. **Owner migration gap.** Drift could be read but not decided from Company → Identity. The owner API
   and responsive surface now record retain, revise or retire with a concrete rationale and Authority
   reference while leaving the artifact untouched.
5. **Silent decision rewrite.** A second request with a different disposition, rationale or Authority
   reference returned the original owner migration decision without naming the conflict. Exact replay
   remains idempotent; conflicting replay now fails because an exercised decision is immutable.
6. **Late and unreachable pillar binding.** Work acquired its identity release when execution started,
   and the accountable-lead prompt neither named nor atomically supported Voice, Visual and Culture
   selection. Queued Work could adopt a newer release, while Staff could race ahead of three manually
   bound contracts. Work now binds the current release at commissioning; one optional
   `--constitution-contracts` object commits only the lead-selected relevant situations in that same
   transaction before the scheduler can observe the Work.
7. **Provider refusal mislabelled as model indecision.** OMP returned OpenAI's explicit
   `credit_balance_exhausted` refusal as assistant content. Exec retried a termination prompt and called
   the result an unparseable decision. Provider-shaped error content is now classified before the
   termination ask, recorded as quota/credit failure and never represented as completed work.
8. **Stale Runtime erased the constitution surface.** The first live treatment container carried an old
   CLI without `restless identity`. Its lead therefore commissioned identity-bearing Work with only Truth
   available. The Runtime image was rebuilt and reconciled; lead guidance now treats a missing identity
   command as a Runtime defect that must be repaired or escalated before commissioning.
9. **Relevant contracts were advisory.** The lead could omit Voice, Visual and Culture without accounting
   for relevance. The standing contract now requires an explicit relevance decision and atomic binding of
   every relevant pillar. The accepted rerun attached 9,306 constitution bytes with all four pillars
   available and no omitted evidence.
10. **Clean completion could strand an incomplete charter.** A reference-capsule Work completed without a
    declared successor. Lead guidance now requires every already-knowable successor and dependency to be
    commissioned up front, preventing research or preparation nodes from becoming dead ends.
11. **Local Runtime builds had split release identity.** Development builds omitted the baked source
    revision, advertised schema 21 while OrgIntel was at schema 33, and sorted source paths differently
    from the daemon. Local and network builds now derive contract/schema versions from the Rust constants,
    bake a development revision, and use the same portable relative-byte path order.
12. **A placeholder repository blocked repo-less Work.** The Harbour lead initially used `company` as a
    repository and worktree name. Runtime correctly refused the nonexistent checkout and the lead replaced
    both producer and critic nodes without repository coordinates. The standing contract now forbids
    placeholder workspace coordinates for ordinary `/company` outputs.

## With/without-system judgement

The deterministic treatment is materially stronger than the old manual baseline:

| Quality risk | Without constitution | With constitution |
| --- | --- | --- |
| Missing pillar | Agent invents a plausible default | Named unavailable; no substitution |
| Conflicting fact | Fluent copy may select one | Dependent expression blocks with exact claim key |
| Artifact currency | Filename/path inference | Exact immutable artifact and evidence binding |
| Correction | Broad “make everything match” request | One concrete affected dependency and owner disposition |
| Company transfer | Logo/colour swap can leak vocabulary | Held-back company keeps distinct truth, voice, visual and conduct evidence |
| Context | Four manual prompt paths | One bounded brief with per-pillar accounting |

The real matched pair used byte-identical task input, `litellm/gpt-5.6-sol`, high reasoning and the same
Runtime. Control completed one nine-channel package for $2.22 but commissioned no independent critic.
Treatment commissioned a critic, which rejected two revisions for invented product proof, overstated
review independence and unsupported voice/authorship. That pair is retained as failure evidence, not a
causal uplift claim: the stale treatment Runtime had bound Truth but not Voice, Visual or Culture.

After Runtime reconciliation and clean-room purge, the affected treatment slice bound all four pillars,
created a source-ranked reference capsule, produced a new candidate, and ran independent native review.
Three review cycles removed unsupported chronology, a founder placeholder and first-person-plural UI
copy. The exhausted producer/reviewer path was then replaced by a bounded provenance editor and a fresh
critic. The critic accepted the exact final package at SHA-256
`b29723925f5e3d051547984f3bf350251db8451f6cf326638aedc23a666d02ed`.
Total treatment spend was $15.75, including failed branches and repairs.

The held-back `harbour_ledger_transfer_test` used its own four-evidence release and all three specialised

## Quality judgement

Sprint 35 closes the implementation and operational acceptance: one source, one release lineage, one
bounded compiler, exact artifacts and concrete owner decisions without flattening the pillars. The
strongest result is not stylistic consistency; it is that missing evidence, critic disagreement,
corrections and company transfer now produce different, inspectable behaviour. The matched pair does
not establish a clean causal effect because its first treatment was under-bound. The reconciled
end-to-end treatment and held-back transfer do prove that the promoted mechanism can converge through
real Restless team assembly, native criticism and bounded replacement without owner tactical rescue.
