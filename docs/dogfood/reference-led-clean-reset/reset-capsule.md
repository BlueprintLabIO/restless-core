# Reset Capsule — fresh Restless landing page

## Outcome

Create one exceptional, locally reviewable Restless landing page that makes the product immediately
understandable: give Restless a consequential outcome, it organises and verifies the work, and it
returns the smallest decision that still needs human authority. The page should feel like the public
threshold of the actual Restless product, not a generic AI-agent website.

## Reset reason

The owner explicitly requested another brand-new landing page to dogfood clean reset. Earlier pages
must not become a repair template. This run tests whether Restless can preserve product truth and the
quality bar while finding a genuinely fresh expression.

## Preserve

- The canonical Cloud repository and `site/` location.
- Astro as the site framework; React islands are allowed and preferred for native React effects.
- Truthful Restless claims: accountable Work and Attempts, evidence, prepared judgement and retained
  human authority.
- Public language that is plain, short, value-oriented and understandable without internal knowledge.
- The actual product's accessibility, responsive and reduced-motion standards.
- Local review only. No publishing, pushing, deployment or hosting mutation.

## Native review

Judge the exact live `/` route after fonts, interaction and layout settle:

- 1440×1000 desktop first viewport and complete scroll;
- 390×844 mobile first viewport and complete scroll;
- reduced-motion state containing the same information;
- keyboard focus and primary CTA;
- console/runtime errors, horizontal overflow and hidden authored content;
- the final conversion/decision section and complete professional footer.

The page must contain at least one memorable product-native visual encounter that explains the
outcome → work → evidence → decision loop without depending on a paragraph. Depth should come from
product demonstration, contrast and rhythm rather than walls of copy.
