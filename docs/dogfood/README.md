# Dogfood scenarios

This directory is the canonical home for Restless dogfood scenarios, their after-actions, and frozen
result bundles. New dogfoods belong here rather than under a generic scenarios directory.

## Numbering and evolution

A dogfood number identifies one persistent outcome charter. Keep that number live while its company
expands, repairs, or repeats the outcome: change its explicit scenario version and preserve an
after-action for each completed run. Allocate a new number only for a materially different company
outcome or a new evaluation question—not for the next slice of the same dogfood.
